# Workshops

Each workshop delivery of *LLM Inference at Scale* gets its own folder. The
handbook itself lives in [`../content/`](../content/); workshop folders only hold
the event-specific outline, demos, and setup instructions.

| Event | Folder | Format | Status |
|-------|--------|--------|--------|
| AI Engineering World's Fair 2026 | [`aiewf-2026/`](aiewf-2026/) | 2 hours, June 29 2026 | Delivered — source material |
| ODSC 2026 | [`odsc-2026/`](odsc-2026/) | TBD | In preparation |

## Conventions

- One folder per event, named `<event>-<year>`.
- Demo notebooks go in `<event>-<year>/demos/`; screenshots in `<event>-<year>/demo_images/`.
- Colab / Molab "Open in" badges embed the full repo path, so they must be
  updated whenever a notebook moves between event folders.
- Don't edit a delivered workshop's folder to prep a new event — copy the demos
  you want into the new folder so the delivered material stays reproducible for
  past attendees.

ODSC 2026 is built on the AIEWF 2026 material: `aiewf-2026/` is the
previous/source material to carry forward and update.
